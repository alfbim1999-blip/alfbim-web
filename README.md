# www.alfbim.com

Web de ALF_BIM: programas de automatización para ingeniería civil.

- La web se publica con GitHub Pages desde la rama `main`.
- Los instaladores (.exe) se publican como archivos de la release `descargas` de este repositorio.
- Precios, contacto, redes e instaladores se cambian en `_src/config.json`; luego se ejecuta `python3 _src/build.py`.
- Las páginas de producto nuevas se describen en `_src/paginas/*.py`; la portada en `_src/index_contenido.py`.
